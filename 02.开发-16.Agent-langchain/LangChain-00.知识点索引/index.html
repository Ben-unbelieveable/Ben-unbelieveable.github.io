LangChain：知识点索引

发表于 2026-08-10 | 更新于 2026-08-28 | 分类于 Agent工程 ， LangChain
LangChain 教程知识点索引：按推荐学习顺序列出专篇主题、核心问题与状态；配合概述与安装使用。

本索引对应 02.开发-16.Agent-langchain 目录下的 LangChain API 教程专篇。
与 LangChain-00.概述与安装 配合：概述讲包地图与最小示例；本表用于按主题跳转与规划写作。

边界：Agent 通用原理（ReAct、选型、案例导航）在 02.开发-16.Agent开发/；图编排（StateGraph、checkpoint）在 02.开发-16.Agent-Langgraph/。

段末注释：LCEL（LangChain Expression Language）= 用 | 连接 Runnable 的声明式链式语法。

1. 如何使用本索引

符号 含义
✅ 已发布，可点击专篇链接
📝 规划中文稿，尚未发布
🔗 外延 相关但不在本目录的文档

专篇文件名格式：LangChain-{模块}-{组件}.md（路径无空格）。

5. 与 LangGraph 目录的衔接

你在 LangChain 学到 下一步（LangGraph 索引）
Tool + 多轮 messages LangGraph checkpointer，或 create_agent（勿再用已弃用的 create_react_agent）
线性 Chain 够用 暂不必上图
要 checkpoint / HITL LangGraph-00.知识点索引

6. 专篇结构约定（读者可见）

每篇专篇默认包含：

  1. 场景切入与一句话定位表
  2. 实现逻辑（一次 invoke 数据流）
  3. 原理说明（底层执行链路为主；对象挂在步骤上展开，禁止只罗列类/方法功能；弃用 API 的 title 带「（弃用）」）
  4. 最小可运行示例 + 预期输出
  5. 重要配置参数表（4～10 项；每项含功能说明：参数做什么、哪一层传入）
  6. 易踩坑（≥2 条）
  7. 小结与官方文档链接

7. 维护说明（作者）

命名与结构以目录内 00.范式-LangChain教程介绍.md 为准（读者正文不引用该文件）。

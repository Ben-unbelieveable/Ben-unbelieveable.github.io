原则-沉没成本-已花的不进方程

发表于 2026-08-12 | 更新于 2026-08-28 | 分类于 方法论 ， 哲思方法论
沉没成本是已发生且不可回收的代价；理性决策只比较未来增量收益与增量成本，不被「都已经投入了」绑架。

流行误解

沉没成本常被听成：

  1. 承认沉没 = 承认失败 = 丢人，所以必须继续。
  2. 忽略沉没成本 = 可以不计后果地浪费。
  3. 和机会成本是一回事。

规则很窄：不可回收的过去支出，不进入「是否继续」的比较；继续与否只看未来。面子与叙事不是经济学变量，但常把人按回坑里。

定义

沉没成本（Sunk cost）：已经发生、且无论当前如何选择都无法收回的成本（金钱、时间、感情投入等）。沉没成本谬误是让这类成本影响继续/停止决策，从而可能在期望净现值为负的路径上加码。

它是 它不是
决策时要剔除的项 「过去努力无意义」的人生判断
与「未来增量」严格分开的记账 忽略违约金、关闭成本等仍可避免的未来支出
止损纪律的基础 鼓励不计机会成本地乱开项目

史源

经济学与管理会计长期区分沉没与可避免成本；行为科学记录「协和谬误」类加码。它要对付的诱惑是：用过去的痛苦为未来的错误买单，好让叙事显得「没白费」。

适用场景

值得用：

  • 项目继续 vs 砍掉、关系/赛道坚持 vs 退出
  • 读不完的书、写不完的重构、打不完的补丁
  • 拍卖、谈判、诉讼中的加码冲动
  • 游戏/产品里故意设计的沉没（养成、战令）——识别被设计

先别用 / 慎用：

  • 把仍可部分回收的资产（可转卖设备、可复用模块）整笔当沉没
  • 忽略停止的未来成本（赔偿、安全债、信誉）——那些不是沉没，是前瞻成本
  • 用「别在意沉没」为不负责任的新浪费开脱

应用步骤

  1. 分割账本：已花不可收回 vs 若继续将新花 vs 若停止将新花/新收。
  2. 剔除沉没：从比较中删除第一类。
  3. 只比前瞻：继续的期望增量净收益 vs 停止/转向的期望增量净收益（含机会成本）。
  4. 处理叙事：单独写「面子/责任叙事」，禁止它偷改第 3 步的数字；若要保留叙事价值，显式定价。
  5. 设止损规则：预先约定指标与日期，减少现场被沉没绑架。
  6. 复用可回收部分：能剥离的能力、代码、关系转为选项价值，而不是为整包沉没陪葬。

操作口令：

问「从今天零投入算起，还会选这条路吗？」；若否，过去花多少都不是留下的理由。

多域例证

项目：已投入人年

已投入不是续建理由。理由只能是：相对转向，未来增量回报仍更好。把已投入当理由，是沉没谬误。

个人：看了半部烂剧

「都看了一半」不是看完的证据。时间沉没；剩下的预期体验才进方程。

谈判：已经报价

沉没的是准备成本；是否加价看未来成交价值与替代，不看「已经谈了三个月」。

例外与坑

坑 1：把关闭成本当沉没

解约金、迁移、安全下线是未来可选的成本，必须进方程。

坑 2：声誉与学习的错误归类

有时「完成」有前瞻声誉收益；把它写进未来收益，而不是偷偷从沉没里走私。

坑 3：与逆向/事前验尸脱节

止损线应在沉没变大之前设定；事后才学「别在意沉没」总是更痛。

用前自检

  1. 哪些成本真正不可回收？
  2. 继续与停止的未来增量各是什么？
  3. 面子叙事有没有污染计算？
  4. 预先止损规则有没有？
  5. 可剥离复用的部分是否已救出？

过去的账已经入账；未来的账才还在你手里。

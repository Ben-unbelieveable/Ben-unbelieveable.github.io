装饰器 · 机制概念

发表于 2026-08-03 | 分类于 编程拾慧 ， python
装饰器的定义、@ 语法等价关系，以及自定义装饰器示例（function_timer）。

装饰器是以函数或类为参数、并返回替换函数或类的可调用对象。可在不修改原定义的情况下附加行为。

修饰函数

@warp 与 foo = warp(foo) 完全等价：装饰器接收原函数，返回一个新可调用对象并绑定到原名字。

写自定义装饰器时注意

  • 计 interval 用 time.perf_counter()，不要用易受系统时钟调整影响的 time.time()
  • 装饰异步函数时 wrapper 须为 async def，内部 await fn(...)
  • 生产环境 profiling 用 cProfile / timeit，计时打印适合开发调试

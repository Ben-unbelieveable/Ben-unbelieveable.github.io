LangGraph：知识点索引

发表于 2026-08-10 | 更新于 2026-08-28 | 分类于 Agent工程 ， LangGraph
LangGraph 教程知识点索引：按推荐学习顺序列出专篇主题、核心问题与状态；配合概述与安装使用。

本索引对应 02.开发-16.Agent-Langgraph 目录下的 LangGraph 图编排教程专篇。
与 LangGraph-00.概述与安装 配合：概述讲安装与最小图；本表用于按主题跳转与规划写作。

边界：ChatModel、Prompt、Tool schema 见 02.开发-16.Agent-langchain/；Agent 通用原理见 02.开发-16.Agent开发/。

段末注释：HITL（human-in-the-loop，人在回路）= 关键步骤暂停，等待人类确认后再继续执行图。

7. 专篇结构约定（读者可见）

每篇默认包含：

  1. 节点表 + 边表（先于代码）
  2. 场景切入与定位表
  3. invoke 生命周期（手算 state）
  4. 原理说明（底层执行链路：channels / reducer / checkpoint 读写时机；对象挂步骤，禁止只列功能）
  5. 最小可运行示例（优先 mock 节点）
  6. 重要配置参数表（含功能说明列）
  7. 执行追踪（≥2 步 state 变化；含环时 ≥2 轮）
  8. 易踩坑（≥2 条）
  9. 小结与官方链接；弃用主题的 title 带「（弃用）」

8. 维护说明（作者）

发布新专篇后更新本表状态与链接。
结构与命名以 00.范式-LangGraph教程介绍.md 为准（读者正文不引用）。

抗体-00.入门-01.抗体设计基础概念与分类术语

发表于 2026-07-20 | 分类于 知识
面向刚接触抗体设计的读者：抗体是什么、普通抗体与单域抗体关系、按类别/来源/片段格式/用途的分类标准，以及从业常用术语表；衔接本系列结构与工具文档。

本文是 抗体设计入门第一站：假定你几乎没有免疫学背景，先把「是什么、怎么分、口头怎么说」说清楚。读完应能听懂同事说的 IgG、Fab、scFv、VHH、人源化、亲和力成熟，并知道去本系列哪一篇深挖。

建议阅读路径：本文 → 认识抗体结构 → 可变区结构 → 亲和力指标。

段末注释：抗体在正式文献中多称 免疫球蛋白（Immunoglobulin，Ig）；口语「抗体」与 Ig 多数场合可互换。

1. 一分钟建立画面

想象免疫系统要认出「外来分子」并贴上标签：

角色 是什么 口语类比
抗原（antigen） 被识别的目标分子（蛋白、毒素、细胞表面分子等） 要抓的「东西」
表位（epitope） 抗原表面上被抗体碰到的那一小片区域 东西上的「把手」
抗体（antibody / Ig） 专门认某个把手的蛋白质 「手套」
互补位（paratope） 抗体上真正接触表位的那一面 手套的「掌心」

抗体设计大致是：给定目标抗原（或表位），找到或造出一把「手套」——要够准（特异性）、够紧（亲和力）、还要能做出来、在人体里站得住（可开发性）。

2. 普通抗体长什么样（以 IgG 为「默认图」）

血清里最常见、药企最常做药的是 IgG（免疫球蛋白 G）。把它想成 Y 形（下图引自本系列结构篇，便于对照域级解剖）：

2.1 四条链

链 英文 干什么
重链 ×2 Heavy chain，H 构成 Y 的长臂 + 茎；带可变区 VH + 若干恒定区
轻链 ×2 Light chain，L 只在两臂；带可变区 VL + 恒定区 CL

完整单体常记为 H₂L₂（两条重 + 两条轻）。

2.2 Fab / Fc / Fv（从业者天天说）

术语 全称直觉 含什么 用途直觉
Fab Fragment antigen-binding，抗原结合片段 VH–CH1 + VL–CL 「一只抓手臂」
Fc Fragment crystallizable，可结晶片段 重链茎部（IgG 多为 CH2–CH3） 半衰期、与受体作用、效应功能
Fv Fragment variable，可变片段 只有 VH + VL 最小「识别核心」
CDR Complementarity-determining region，互补决定区 VH/VL 上各 3 条高变环 真正「摸」表位的环；共 六条（H1–H3、L1–L3）
FR Framework region，骨架区 CDR 之间的相对保守段 撑住折叠与配对几何

段末注释：VH / VL = 重/轻链可变域；CH / CL = 恒定域。结构细节见 抗体-01.结构-01。

价（valency）：IgG 有 两个 Fab → 双价，可同时抓两个相同/邻近表位，带来 亲和力增强（avidity） 效应（「一只手 vs 两只手」）。

3. 单域抗体和普通抗体是什么关系？

不是「普通抗体缺了结构信息」。二者是 分子格式（format） 不同。

常规抗体（如人/鼠 IgG） 单域抗体（sdAb）
结合核心 VH + VL 成对 一个可变域即可（常见 VHH）
典型大小 完整 IgG ~150 kDa VHH ~12–15 kDa
类比 双手协作抓东西 一只手也能抓
常见来源 人、鼠、兔等四链抗体 骆驼科重链抗体的 VHH；鲨鱼等 VNAR

VHH（variable domain of the heavy-chain-only antibody）：骆驼科天然存在「只有重链」的抗体，其可变区可单独稳定存在并结合抗原；药物/工程里常称 纳米抗体（nanobody）。

段末注释：sdAb（single-domain antibody，单域抗体）是上位概念；口语里「纳米抗体」多特指骆驼科 VHH 一类。

和「序列多、结构少」的关系（别混淆）：

  • 定义：sdAb = 单域就能结合的格式。
  • 数据现象：展示文库筛出大量 sdAb 序列，每个都有晶体复合物的比例往往较低 → 计算上更常做 纯序列亲和力预测（如 DLP-Affinity 用 sdAb-DB）。那是数据生态，不是定义。

4. 抗体怎么分类？（多把尺子，不是一棵树）

同一分子可以同时属于多类标签。从业者按任务换尺子。

4.1 按重链类别（isotype，同种型）——「哪一类 Ig」

分类标准：重链恒定区基因/序列类型（决定血清行为与效应功能）。

类别 常见形态 场景直觉
IgG 单体 Y 形 治疗性抗体默认主力；半衰期长
IgM 常五聚体 初次应答早；补体强；工程药较少用完整五聚体
IgA 单体/二聚体 黏膜免疫；分泌型带分泌片
IgE 单体 过敏、寄生虫；过敏药靶点相关
IgD 单体 膜上 B 细胞相关，血清少

人类 IgG 还有 IgG1/2/3/4 亚类：效应功能、铰链、二硫键布局不同，选亚类是成药常见决策。

4.2 按轻链型——κ / λ

标准：轻链恒定区是 κ（kappa） 还是 λ（lambda）。同一天然抗体分子两条轻链型别一致。设计时通常选定一种，较少「混型」。

4.3 按物种来源与「人源化程度」——免疫原性尺子

标准：序列/结构有多像「人的抗体」（降低 免疫原性，减少抗药抗体）。

标签 含义 场景
鼠源（murine） 几乎全是鼠序列 早期研究、诊断；人体用药易惹免疫反应
嵌合（chimeric） 鼠可变区 + 人恒定区 过渡方案；名称常带 -xi-（如 rituximab 一类命名习惯）
人源化（humanized） 人骨架 + 移植鼠 CDR 等 常用成药路径；名称常带 -zu-
全人（fully human） 可变区也来自人库/转基因鼠等 进一步降免疫原性；名称常带 -u-

段末注释：免疫原性（immunogenicity） = 诱发机体对该药产生抗体的能力；治疗抗体要尽量「像自己人」。

4.4 按分子格式（format）——设计与表达尺子

标准：保留了哪些结构域、有几条链、几个结合价。下图用「域积木」对照五种基础格式：实心 = 保留，虚线/叉 = 缺失。

格式 保留 缺失（相对完整 IgG） 价 典型用途
完整 IgG VH、VL、CH1、CL、铰链、CH2、CH3（H₂L₂） — 2 治疗默认；要半衰期与 Fc 效应
Fab 单臂：VH–CH1 + VL–CL 另一臂；整段 Fc（CH2–CH3）；多价铰链连接 1 诊断、片段药、减效应
F(ab’)₂ 两臂 + 部分铰链相连 Fc（CH2–CH3） 2 双价但不要 Fc 效应
scFv VH + VL + 连接肽（单链） 全部恒定区（CH1/CL/铰链/Fc）；不再是四链组装 1 小、易表达；CAR-T、双抗模块
VHH / sdAb 单个可变域（常 VHH） 轻链全无；无 CH1/CL/Fc（除非再融合） 1 穿透、隐蔽表位、模块拼装

读图要点：从左到右大致是「切掉 Fc → 再丢掉一条臂 / 恒定区 → 只剩可变域」；scFv 是把 Fv「焊成一条链」，VHH 是天然单域路线，二者都不是简单酶切产物。

格式 组成关系（工程拼装） 相对基础格式多了什么
双特异性（bispecific） 两个不同互补位装在同一分子 第二特异性（可基于 IgG/片段/VHH 等多种骨架）
ADC 抗体（多为 IgG）+ 接头 + 毒素载荷 载荷与接头；抗体骨架仍可含完整 Fc
CAR 胞外结合域 常 scFv 或 VHH 挂在细胞膜蛋白上 跨膜/胞内信号域（属细胞工程，不只是可溶抗体）

片段从哪来：对照上文 图 5（papain → Fab；pepsin → F(ab′)₂）。工程上还可把 Fv 串成 scFv，或走骆驼路线用 VHH，再拼成双抗 / ADC / CAR 模块。

4.5 按制备方式——「从哪来的」

类型 标准 用途直觉
多克隆（polyclonal） 血清里一群不同克隆的混合物 试剂、多表位覆盖；批间差大
单克隆（monoclonal，mAb） 单一 B 细胞克隆产物，序列均一 药与精确定量的主流
重组抗体（recombinant） 基因合成/克隆后在宿主表达 工程改造、人源化、格式切换

杂交瘤、噬菌体/酵母展示、单 B 细胞测序、计算设计等，都是拿到 单克隆序列 的不同产线。

4.6 按用途场景（产品标签）

场景 常见格式 关心什么
治疗性抗体 IgG、双抗、ADC 亲和力、特异性、PK、免疫原性、CMC
诊断/科研试剂 IgG、多抗、标记 Fab 效价、批间一致性、交叉反应
细胞治疗模块 scFv、VHH 大小、稳定性、表达
成像探针 片段、sdAb 清除快、穿透

5. 抗体设计从业者常挂嘴边的词（术语速查）

5.1 结合与药效

术语 说明
亲和力（affinity） 一个结合位点与表位结合的强度；常用 (K_{\mathrm{D}})（越小越紧）
(K_{\mathrm{D}}) 解离平衡常数；详见 指标总览
(k_{\mathrm{on}}/k_{\mathrm{off}}) 结合/解离速率；「粘得快不快、掉得慢不慢」
亲和力增强（avidity） 多价同时结合带来的表观变紧
特异性（specificity） 认准目标、少误认别的分子
交叉反应（cross-reactivity） 误认同源蛋白/物种间靶点
中和（neutralization） 结合后阻断病原/毒素功能
效应功能（effector function） 经 Fc 触发 ADCC/CDC 等杀伤或清除
ADCC / CDC / ADCP 抗体依赖细胞介导细胞毒 / 补体依赖细胞毒 / 吞噬

5.2 发现与工程流程

术语 说明
免疫（immunization） 用抗原刺激动物产生抗体应答
杂交瘤（hybridoma） 融合 B 细胞与骨髓瘤，经典造 mAb
展示文库（display library） 噬菌体/酵母等表面展示抗体片段并淘选
淘选（panning） 多轮结合–洗脱富集 binders
命中（hit）/ 先导（lead） 初筛阳性 → 优化后的候选
亲和力成熟（affinity maturation） 突变 + 筛选把亲和力做高
人源化（humanization） 降低异种序列免疫原性
可开发性（developability） 表达、聚集、粘度、稳定性、化学降解等 CMC 友好度
PK / PD 药代动力学 / 药效学
半寿期 / FcRn IgG 靠 FcRn 循环延长血中停留

5.3 序列与结构「行话」

术语 说明
胚系（germline） 未突变的 V/D/J 基因模板
V(D)J 重排 组装可变区基因多样性的机制
体细胞超突变（SHM） 应答中引入点突变，亲和力成熟的自然版
编号（numbering） Kabat / Chothia / IMGT 等残基编号体系；写论文、做人源化必须声明
注释（annotation） 标出 FR/CDR、链型、胚系；工具见 IMGT/ANARCI/RIOT 系列
对接（docking） 计算抗体–抗原复合物姿势
表位作图（epitope mapping） 实验/计算定位结合在抗原哪一块

5.4 容易混的一对

别混 区别
亲和力 vs 效价（titer） 前者是结合强度；后者常指血清/试剂「稀释到还有信号」的稀释度
(K_{\mathrm{D}}) vs (EC_{50}) (K_{\mathrm{D}}) 偏结合热力学；(EC_{50}) 是功能曲线一半有效浓度，受格式与体系影响
特异性 vs 选择性 口语常混用；严格说选择性更强调在多个相似靶之间偏好某一个
Ig 类别 vs 分子格式 IgG/IgM 是同种型；scFv/VHH 是工程片段格式

7. 刚入门做设计时，先问自己的五个问题

  1. 靶点是什么？ 可溶蛋白还是膜蛋白？表位是否已知？
  2. 要完整 IgG 还是片段/ sdAb？ 要不要 Fc 效应与长半衰期？
  3. 来源策略？ 免疫动物、展示库、计算设计、还是已有序列优化？
  4. 成功标准？ (K_{\mathrm{D}})、细胞功能、种属交叉、表达量、聚集？
  5. 编号与注释约定？ 团队统一 IMGT 还是 Kabat？（避免 CDR 边界各说各话）

小结

  • 抗体是识别抗原表位的 Ig 蛋白；设计围绕 特异性、亲和力、格式、可开发性。
  • 普通 IgG = 重轻链配对的双价分子；sdAb = 单域即可结合的另一类格式。
  • 分类要用多把尺子：同种型、轻链型、人源化程度、分子格式、制备方式、用途。
